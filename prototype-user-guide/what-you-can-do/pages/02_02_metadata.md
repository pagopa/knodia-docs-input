The definition of a **Cross-Border E-Service** is implemented by the **Producer** on the **Knode** where it is onboarded.

The **Producer** must define the following metadata:
- **Name**: The name of the **Cross-Border E-Service**, a string of up to 60 characters.
- **Description**: The description of the **Cross-Border E-Service**, a string of up to 250 characters.
- **Categories (optional)**: Categories associated with the **Cross-Border E-Service**, useful for classification and simplifying searches by **Consumers**.
