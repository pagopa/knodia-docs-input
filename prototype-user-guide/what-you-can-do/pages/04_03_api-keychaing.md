The **Knode API Keychain** is created by the organization on the **Knode** where it is onboarded.

A **Knode API Keychain** is associated with the operators who can manage it and, specifically, stores the public keys used for client authentication.

The public keys for the **Knodia Prototype** are [JWK](https://datatracker.ietf.org/doc/html/rfc7517) [RS256](https://datatracker.ietf.org/doc/html/rfc7518) compliant and stored in PEM format.

The organization uses the public keys registered in the **Knode API Keychain** to identify its clients when accessing the **Knodia APIs** of the **Knode** where it is onboarded.
