The **Production Keychain** is created by the **Producer**, on the **Knode** where it onboarded.

A **Production Keychain** is associated with the operators who can manage it and, specifically, stores the public keys used.

The public keys for the **Knodia Prorotye** are [JWK](https://datatracker.ietf.org/doc/html/rfc7517) [RS256](https://datatracker.ietf.org/doc/html/rfc7518) and stored in PEM format.

The **Producer** associates a **Cross-Border E-service**, if necessary, with the keychain containing the public keys used to sign the responses of the same **Cross-Border E-service**.
