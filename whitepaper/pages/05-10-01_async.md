Consumption, as described so far, occurs synchronously: the *Cross-Border E-Service* responds to the *Consumer*’s request with the requested data. A *Knode* must also provide an alternative asynchronous mode that *Producers* can use to respond.

A *Producer* that intends to use the asynchronous mode for a *Cross-Border E-Service* must declare the characteristics of the callback endpoint that the *Consumer* must implement to receive the data.

When calling the *Cross-Border E-Service*, the *Consumer* specifies the callback endpoint. When the *Producer* completes processing the request and is ready to return the resources, it calls the callback endpoint specified by the *Consumer*.

The *Knodia Consortium*, referred to in § [Considerations on the governance of Knodia](./05-11-00_federation-governance.md), capitalizing on the effects of the proposed experimentation, defines in detail how to implement this functionality.
