# Knodia documentation repo
This repo contains the content needed to view the Knodia documentation in GitBook.

The repo includes:
- **Knodia Whitepaper**, which defines the *cross-border authentication and authorization framework* proposed model;
- **Knodia Executive Summary**, a synopsis of the *cross-border authentication and authorization framework* proposed model;
- **Knodia Prototype User Guide**, useful documentation for users of the Knodia Prototype.
