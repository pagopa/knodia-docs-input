# Knodia documentation 
This repo contains the source code for Knodia documentation.

The repo includes:
- [Knodia Whitepaper](whitepaper/pages/01_abstract.md), which defines the *cross-border authentication and authorization framework* proposed model;
- [Knodia Executive Summary](executive-summary/pages/01_abstract.md), a synopsis of the *cross-border authentication and authorization framework* proposed model;
- [Knodia Prototype User Guide](prototype-user-guide/getting-started/pages/01_prototype-overview.md), useful documentation for users of the Knodia Prototype.
