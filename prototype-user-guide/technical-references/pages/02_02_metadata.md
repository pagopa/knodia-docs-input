The definition of a **Cross-Border E-Service** is implemented by the **Producer**, on the **Knode** where it onboarded.

The **Producer** must define the metadata:
- **Name**: the name of **Croos-Border E-Service**, a string of up to 60 characters;
- **Description**: the description of **Croos-Border E-Service**, a string of up to 250 characters;
- **Categories (optional)**: the **Croos-Border E-Service**, useful for classifying the same and simplifying the search by **Consumers**.
