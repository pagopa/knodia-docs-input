The access request is the digital process performed by a **Consumer** to request the use of a **Cross-Border E-service** published by a **Producer**.

The **Consumer**, after searching for the **Cross-Border E-service** on the **Knode** del **Producer**, can initiate the access request only if they meet the **Attributes** indicated into the **Consumption Requirements** definiti dal **Producer**.

The access request involves two steps:

- **Authorization request**, initiated by the **Consumer** on their own "Knode";
- **Purpose Statement**, the **Consumer**'s declaration the purpose of use and how the received data will be processed.

Please note that in the **Knodia Prototype**, the **Cross-Border E-service** can be defined only in **Provide-data** mode, thus placing the **Consumer**'s responsibility for creating the **Purpose Statement**. For **Cross-Border E-service** mockups that implement the **Receive-data** mode, the **Purpose Statement** is created by the **Producer**.
