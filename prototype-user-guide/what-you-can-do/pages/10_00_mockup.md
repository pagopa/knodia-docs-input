# WIP

To facilitate the use of the **Knodia Prototype", some Cross-Border E-Service mockups have been published and made available to all participants in the experiment.

## Orion Cross-Border E-Service mockup

### Cross-border e-service Orion 01
Simulates the retrieval of a natural person's date of birth.

| Feature | Description |
|--|--|
| Name | *Mockup 01 Personal Information (Bearer) - Orion* | 
| Knodia Producer | *Mockup Confederate Organization Orion* |
| Knodia Category | *citizen.residence.birth_date* |
| Entities used | *natural_person* |
| Typology | *Provide-Data with bearer token* |

Technical details can be consulted via the Knode Catalogs.
