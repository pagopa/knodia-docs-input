In the **Knodia Prototype**, **Knodes** implement additional functionalities defined in the [**Knodia whitepaper**](../../../whitepaper/pages/01_abstract.md) as practical examples for users.

Specifically, these functionalities include:
- **Distribution of data change signals (Signal Hub)**: Allows users to experiment with the distribution of entity change signals.
- **Producer Keychains**: Enables users to create and associate keychains with their **Cross-Border E-Services** to sign API responses (see [Producer Keychain](04_02_producer-keychain.md)).
- **E-Service Templates**: Provides pre-defined templates for users to easily define their **Cross-Border E-Services**.
- **Purpose Statement Templates**: Provides templates to assist users in compiling their **Purpose Statements**.
- **Asynchronous communication**: Provides a **Cross-Border E-Service** mockup implementing the Asynchronous Request-Reply with Polling Message Exchange Pattern (MEP) for user testing (see [Mockup exposed by Knodes](10_00_mockup.md)).
