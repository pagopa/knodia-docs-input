# Knodia documentation repo

This repo contains the source code for Knodia documentation.

The repo includes:

- /executive-summary, which contains everything needed to render the Knodia executive summary section on GitBook
- /prototype-user-guide, which con contains everything needed to render the Knodia prototype section on GitBook
- /whitepaper, which contains everything needed to render the Knodia whitepaper section on GitBook
