The **Knode API Keychain** is created by the organization, on the **Knode** where it onboarded.

A **Knode API Keychain** is associated with the operators who can manage it and, specifically, stores the public keys used.

The public keys for the **Knodia Prorotye** are [JWK](https://datatracker.ietf.org/doc/html/rfc7517) [RS256](https://datatracker.ietf.org/doc/html/rfc7518) and stored in PEM format.

The organization uses the public keys registered in the **Knode API Keychain** to identify its clients using the **Knodia API** of the **Knode** where it is onboarded.
